# MUSE by novikova — прототип

## Как открыть
Дважды щёлкните по файлу index.html — он откроется в браузере (Chrome, Safari, Edge).
Нужен интернет: шрифты загружаются из Google Fonts.

## Что внутри
- index.html — весь прототип в одном файле: заставка, тарифы, кабинет стилиста,
  кабинет клиента, рекомендованные цвета, «Палитра в кармане», модуль «Рост», админка.
- PRODUCT.md — паспорт продукта: аудитория, бренд, принципы.

## Важно
- Данные сохраняются только в этом браузере на этом устройстве.
  Кнопка «Сбросить демо» возвращает примеры.
- Скачивание PDF и таблицы CSV работает только в версии внутри Claude;
  при открытии файла с компьютера появится сообщение, что скачивание недоступно.
- Оплаты и письма в прототипе ненастоящие.
